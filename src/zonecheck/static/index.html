Can this vehicle enter the zone?

Type a Dutch licence plate and pick a city. zonecheck reads the official NDW emission-zone rules and the RDW vehicle record, and tells you if the vehicle can enter the low-emission zone (milieuzone) or zero-emission zone.

Use the API

curl '/access?kenteken=AB-123-C&zone=Amsterdam'

Every answer is allowed, not_allowed or unknown, with the deciding rule conditions, the vehicle facts used and the feed timestamp. Full reference: API documentation.
